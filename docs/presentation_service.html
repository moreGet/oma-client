지금의 불편함

보안망의 AI는 답만 주고, 실행은 내 몫

보안망에서는 똑똑한 외부 AI 도구를 쓸 수 없습니다. 쓸 수 있는 건 "물어보면 답만 주는" 챗봇뿐이었죠.

그래서 AI가 알려준 대로 파일을 찾고, 고치고, 명령을 실행하는 일은 결국 사람이 손으로 다시 해야 했습니다.

우리의 통찰

필요한 건 더 똑똑한 답이 아니라,
대신 일해줄 손이었습니다

사람은 "무엇을 원하는지"만 말하면 충분합니다. 찾고·만들고·바꾸고·확인하는 실제 손작업은 AI가 맡습니다. 단, 보안망을 벗어나지 않고, 회사가 통제할 수 있는 방식으로.

🧾

AI가 스스로 한 일

  • ✓ 폴더에서 엑셀 12개 찾기 (glob)
  • ✓ 각 파일 읽어 부서·금액 추출 (read_excel)
  • ✓ 지난달 파일과 대조해 증감 계산
  • ⏸ 보고서 파일 생성 — 승인 요청 (write_excel)
  • ✓ 승인 후 생성 완료 · 결과 요약 보고

진행 상황은 화면 상단 작업 계획 카드에 단계별로 표시됩니다 — 지금 무엇을 하는 중인지 보입니다.

읽기는 알아서, 쓰기·삭제·실행은 확인 후. 사람은 목표와 승인만 담당합니다.

"AI를 쓰면 내부 정보가
국외로 나가지 않나요?"

나갈 경로 자체가 없습니다. 앱은 외부 AI 회사에 직접 접속하지 않습니다.

앱이 통신하는 곳은 사내 서버 단 한 곳뿐입니다. 외부 AI 서비스의 API 키가 앱에 아예 없어서, 설령 노트북을 분실해도 외부로 데이터를 보낼 수단이 없습니다.

정리되는 업무 기록

대화를 프로젝트로 묶고, 어디서나 이어보기

업무별로 대화를 모아두면, 나중에 다시 찾기 쉽습니다.

"사내포털 리뉴얼", "월말 정산" 처럼 프로젝트를 만들고 대화를 끌어다 놓아 분류하세요. 모든 기록은 기본적으로 내 PC에 저장되며, 원할 때만 회사 서버와 동기화해 사무실·재택 등 다른 PC에서 그대로 이어 봅니다.
