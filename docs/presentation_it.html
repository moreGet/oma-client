에이전트 루프

IAgentOrchestrator 상태 머신

질의 + 도구 스키마
→
서버 SSE 스트림
→
stop_reason 판정
→
도구 실행(3중 게이트)
→
tool 메시지 재요청 ↺
  • › SSE 이벤트: message_start · content_delta{delta} · tool_call{id,name,arguments} · message_stop{stop_reason,usage} · error
  • › stop_reason == tool_use → 클라가 도구 실행 후 tool 메시지로 재요청(루프 지속). end_turn → 종료
  • › tool_call.arguments는 JSON 문자열로 송수신, 클라가 객체 복원. 루프 상한 MaxIterations(기본 25)
  • › max_tokens는 서버 제어 — 클라 설정 제거, 와이어엔 상수만 전송. metadata.client_version에 SemVer 동봉
  • › 파일 첨부: messages[].attachments[]에 base64로 동봉(파일당 ≤10MiB)
보안 모델 ① · 도구 실행 결정

3중 게이트 — 정책 → 권한 → 샌드박스

모델이 tool_call을 보내면 세 게이트를 순서대로 통과해야 실제 OS 조작이 일어납니다.

1
서버 도구 정책
IToolPolicyService — cached/realtime로 실행 허용 통제. 차단 시 승인·실행 건너뛰고 사유를 모델에 피드백
2
로컬 권한 게이트
IPermissionService — ToolRisk × PermissionMode(Manual/AutoSafe/FullAuto). 위험 작업은 승인 카드
3
샌드박스 검증
IWorkspaceContext.ResolvePath — 활성 워크스페이스 루트 밖 경로면 거부(throw)

중앙 집중 오류 처리: 도구 예외는 AgentOrchestrator.ExecuteCallAsync에서 전부 ToolResult.Fail로 변환 → 앱은 죽지 않고 모델에 에러 피드백.

보안 모델 ② · 서버 제어형 도구·보안

2중 안전 — 클라 디폴트 ∪ 서버

최종 적용값 = 클라 내장 디폴트(바닥) ∪ 서버 값(추가 제약). 서버는 더 조일 수만 있고, 미구현/오프라인이면 디폴트만으로 정상 동작(graceful).

🧰

도구 노출·실행 통제

GET /api/v1/tools/policy(cached/realtime). 비활성 도구는 모델에 노출조차 안 됨 + 실행 차단.
노출/허용 = 내장 ∩ enabled − disabled. realtime은 POST /tools/authorize로 매 호출 인가(응답 없으면 fail-closed).

🚫

위험 명령 차단

SecurityValidator = 클라 내장 블랙리스트 ∪ GET /security/command-policy 추가 패턴.
서버는 추가만(디폴트 제거 불가). 정규식은 컴파일 검증 + 매치 타임아웃으로 ReDoS 방어, substring 타입 지원.

서버 값은 로그인 시 1회 로드·세션 캐시(도구 정책과 동일 라이프사이클) — 변경은 재로그인 반영.

보안 모델 ③ · 멀티루트 샌드박스

최대 10개 루트 OR 검증

IWorkspaceContext가 모든 파일/셸 경로를 활성 루트 기준으로 검증.

  • ✓ 최대 10개 루트 동시 등록 + 폴더별 Enabled 토글(전역 설정, 프로젝트 비귀속)
  • ✓ ResolvePath: 상대→주 루트 Combine, 검증은 활성 루트 OR(하나라도 내부면 통과)
  • ✓ 심볼릭/실경로(RealPath) 정규화 후 비교로 ..·절대경로·정션 탈출 차단
  • ✓ 비활성(토글 off) 루트는 샌드박스 통과 불가. run_command cwd = 주 루트

실시간 채팅 ① · 사람↔사람 메신저

LLM과 별개인 실시간 메신저

/agent/chat(LLM)과 완전히 별개인 사람↔사람 메신저. 단체(group)·1:1(direct) 방, 송수신·수정·삭제, 읽음·안읽음, 타이핑, presence(온라인), 멘션, 첨부, 멤버 관리를 실시간 반영.

💬

방 & 메시지

단체/1:1 방, 좌·우 말풍선, 무한 스크롤 이력, 본인 메시지 수정·소프트 삭제("삭제된 메시지" 자리표시).

✅

읽음 & 안읽음

멤버별 읽음 위치(단조 증가), 트레이·사이드바·타이틀바에 전역 안읽음 배지 실시간 동기화.

🟢

타이핑 & presence

타이핑 인디케이터, 온라인 상태 점(허브 메모리 전용·비영속). 연결점 녹/주황/적.

@

멘션 · 첨부 · 멤버

멘션 하이라이트·자동완성·피드, 첨부(≤10MiB), 단체방 멤버 추가/강퇴(생성자)/나가기.

진입: 트레이·사이드바 "메신저"(안읽음 Pill) → 별도 ChatMessengerWindow(좌 방목록 / 우 대화방). 메신저 최초 표시 시 1회 StartAsync(WS connect + unread), ReturnToLogin/종료 시 StopAsync.

실시간 채팅 ③ · 네트워크·UI 최적화
