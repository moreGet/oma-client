사내 AI를
실제로 일하게 만들다

Claude Code·Codex를 설치할 수 없는 보안망에서, 사내 AI API와 연동해 지정한 폴더 안의 파일·셸·시스템 작업을 자율 수행하는 Windows 네이티브 에이전트.

C# · .NET 10 · WPF · MVVM  |  → 다음 슬라이드

왜 탄생했나

보안망에는 에이전트가 없었다

사내망은 외부 SaaS가 막혀 있다.
그래서 가장 강력한 도구를 못 쓴다.

Claude Code, Codex 같은 에이전트는 외부 연결과 설치를 전제로 한다. 폐쇄망 개발자는 "AI가 대신 일해주는" 경험에서 소외된다.

기존 — 막힘

  • ✕ 외부 에이전트 설치 불가
  • ✕ 단방향 채팅이 전부
  • ✕ 답변을 사람이 다시 손수 실행

OhMyAgent — 열림

  • ✓ 사내 API로 완결
  • ✓ 도구를 직접 실행
  • ✓ 결과까지 자동 수행
왜 있어야 하나

"응답을 보여주는" 앱이 아니라
"일을 끝내는" 앱

핵심 전환점 — 서버가 내린 도구 호출을 클라이언트가 실제로 실행하고, 그 결과를 다시 서버로 돌려주는 루프를 돈다.
